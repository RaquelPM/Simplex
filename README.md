## Compilação

Para compilar o projeto, execute:

```bash
make
```

## Execuçao

```bash
solve ./caminhodainstancia mps <preprocessamento> <refatoracao>
```

## Parâmetros

- `<caminho_da_instancia>`  
  Caminho para o arquivo da instância.

- `<preprocessamento>`  
  Define se será usado pré-processamento:  
  - `0` → sem pré-processamento  
  - `1` → com pré-processamento  

- `<fatoracao>`  
  Número de matrizes eta permitidas.
